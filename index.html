What "tax increment" means

When land inside a district or project area gains value, the property tax on that increase (the increment) can be set aside for the district, authority, or developer's infrastructure instead of flowing to the usual taxing entities, such as the county, school district, and city. It is set aside for a fixed term, often 20 to 40 years.

Not every pin here uses tax increment. Some districts rely on their own property tax or on assessments, and some items are state loans. Each pin says which.

How this map is sourced

Every figure comes from a public document: a resolution, plan, budget filing, minutes, or an agency's own website. News reports are cited only where noted. Where an agency's own documents disagree with each other, the pin says so instead of choosing one number.

Drafts are labeled as drafts. An unsigned agreement is not an operative contract.
